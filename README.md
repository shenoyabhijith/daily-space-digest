# ☄️ Daily Space Field Notes

A daily HTML field note exploring planets, moons, asteroids, and comets from our Solar System. Each day features a new article with:

- 🖼️ **NASA imagery** — auto-fetched from NASA Image Library
- 📊 **Composition facts** — what it's made of, key stats
- 🧠 **Why it's fascinating** — science that makes you stop and think
- 🌌 **NASA APOD** — Astronomy Picture of the Day side quest
- 🔗 **Source links** — NASA/JPL/ISRO/ESA mission pages

## 🛠 Technical

- **Standalone Python 3.10+ script** — no pip dependencies
- **Images** from NASA Image Library & APOD (DEMO_KEY API tier)
- **Auto-deployed** via GitHub Pages
- **Generated fresh every day** via Hermes cron job
